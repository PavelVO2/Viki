# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## О проекте

Сайт совмещает две вещи на одной площадке: личный бренд «Паша Биатлон» и продвижение центра тестирования **O2MAX**. Это не два отдельных сайта — это одно пространство, где личная история работает на доверие к экспертизе O2MAX. Подача — стилизация под статью Википедии (инфобокс, сноски, pull-quote).

Профиль владельца проекта — в [profile.md](profile.md), прочитай его, чтобы понимать, для кого и зачем этот проект.

## Структура и команды

Сборки, линтера и тестов нет — проект намеренно без инструментов (см. «Жёсткие ограничения» ниже). Чтобы посмотреть результат, достаточно открыть [index.html](index.html) в браузере.

- [index.html](index.html) — единственная страница сайта; вся разметка и CSS встроены inline (`<style>` в `<head>`, без внешних файлов и препроцессоров).
- [profile.md](profile.md), [про-меня.md](про-меня.md), [проекты.md](проекты.md), [факты.md](факты.md) — русскоязычные исходники/черновики текста от владельца. Текст в index.html собран из них; при правке контента сверяйся с этими файлами, а не придумывай факты заново.
- [images/](images/) — фотографии, использованные в index.html, плюс [images/CREDITS.md](images/CREDITS.md) с источниками и лицензиями (CC BY / CC BY-SA / CC0 через Openverse) для части файлов. Некоторые файлы в images/ (gold.jpg, vault.jpg, money.jpg, tophat.jpg, castle.jpg) в текущей версии index.html не используются — остались от более раннего варианта дизайна.

## Тон и стиль текста

Тон — смешанный, и смешивать его нужно осознанно, а не размывать в одно среднее:

- Разделы **о себе** (про-меня, факты, личная история) — живо, с юмором, неформально. Ориентир — стиль `про-меня.md` и `факты.md`.
- Разделы **про O2MAX, цифры, тестирование, показатели** — серьёзно и точно, без шуток и стёба. Данные должны звучать как данные, а не как гэг.

Не смешивай эти два регистра внутри одного блока — переключение тона должно происходить на границах разделов, а не внутри абзаца про лактат.

## Дизайн

Главный враг — перегруженность. Держать страницу лёгкой:

- минимум блоков, никаких лишних секций «на всякий случай»;
- воздух и пространство важнее плотности информации;
- если сомневаешься, добавлять ли элемент — не добавляй.

## Жёсткие ограничения

- **Только статика.** Чистый HTML/CSS/JS. Никаких React/Vue/Svelte, никаких сборщиков и бандлеров, никакого бэкенда.
- **Не разрастаться.** Без CMS, без базы данных, без лишних страниц и сервисов «на будущее». Проект должен оставаться маленьким и управляемым — одна цельная площадка, а не платформа.
